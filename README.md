# Accessible Medical Care Navigator
> HackGwinnett 6.0 AI-Division Submission

### Current State
The project can perform OCR on uploaded images of documents. It can then give explanations at various reading levels for easy comprehension. 

When addressing a specific part of the article in its explanation, it will highlight the area of the article it is referring to. 
> There are some sample documents included with premade explanations and analyses, purely for demonstration purposes.

Further, the local AI model will respond to document-specific questions the user may ask. 

Documents can be saved in vaults which require encrypted passwords to unlock, which features a recovery-key.

Onboarding contains configurable accessibility settings that can always be manipulated later within the app settings.

There is a Windows installer available to test the project in its current state.
